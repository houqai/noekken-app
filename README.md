# Noekken

Noekken for Windows 10 and 11 (x64) and Android 8 or newer (64-bit).

Download the latest version from [Releases](https://github.com/houqai/noekken-app/releases/latest): on Windows run the installer as administrator, on Android open the APK. Sign in with your account key from [noekken.com](https://noekken.com).
